# AI 原理教室

零基础也能看懂的 AI 原理教学网站：神经网络、训练原理、主流架构（CNN / RNN / Transformer / 扩散 / MoE）、注意力机制分步图解、58 个核心名词词典，全部图解为手绘 SVG。

在线访问：https://xwx0708.github.io/ai-learn/

## 本地运行

```bash
npm install
npm run dev
```

## 内容基准

文字以《动手学深度学习》(d2l.ai)、Understanding Deep Learning (Simon Prince)、3Blue1Brown、The Illustrated Transformer (Jay Alammar) 等权威教材为准确性基准，改写为零基础可读的中文。

## 技术栈

React 19 + TypeScript + Vite + Tailwind CSS，纯前端，无后端。
